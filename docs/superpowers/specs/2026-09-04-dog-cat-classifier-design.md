# 개/고양이 판별 서비스 설계

## 목적

사용자가 사진을 업로드하면 브라우저에서 즉시 개인지 고양이인지 판별해주는 웹 서비스. 백엔드, API 키, 서버 비용 없이 동작한다.

## 기술 스택

- 순수 HTML/CSS/JS (빌드 도구 없음)
- TensorFlow.js + MobileNet (CDN에서 로드하는 사전학습 이미지 분류 모델)
- 정적 파일이므로 Vercel 등에 그대로 배포 가능

## 파일 구성

- `index.html` — 페이지 구조 (드롭존, 파일 입력, 미리보기, 결과 영역)
- `style.css` — 스타일
- `app.js` — 모델 로딩, 이미지 처리, 판별 로직

## 화면 흐름

1. 페이지 진입 시 백그라운드에서 MobileNet 모델 로딩 시작, 로딩 중 인디케이터 표시
2. 사용자가 드롭존에 이미지를 드래그하거나 클릭해서 파일 선택
3. 업로드한 이미지를 미리보기로 표시
4. "판별 중..." 표시 후 결과 출력:
   - `🐶 개입니다 (신뢰도 87%)`
   - `🐱 고양이입니다 (신뢰도 92%)`
   - `❓ 개나 고양이로 보이지 않습니다`

## 판별 로직

MobileNet은 ImageNet 1000개 클래스를 분류하며, 그중 개 품종 관련 클래스가 약 120개, 고양이 관련 클래스가 약 6개(tabby, tiger cat, Persian cat, Siamese cat, Egyptian cat 등) 포함되어 있다.

1. 업로드된 이미지에 대해 MobileNet의 상위 5개 예측 클래스와 확률을 가져온다.
2. 미리 정의한 개 품종 키워드 목록과 고양이 키워드 목록에 각각 매칭되는 예측들의 확률을 합산한다.
3. 개 합산 확률과 고양이 합산 확률 중 더 높은 쪽이 기준치(30%) 이상이면 해당 결과와 신뢰도(%)를 표시한다.
4. 둘 다 기준치 미만이면 "개나 고양이로 보이지 않습니다"를 표시한다.

## 에러 처리

- 모델 로딩 실패(네트워크 문제): "모델을 불러오지 못했습니다. 새로고침 해주세요" 메시지 표시
- 이미지가 아닌 파일 업로드: "이미지 파일만 업로드 가능합니다" 안내, 판별 시도하지 않음
- 판별 중 예외 발생: 콘솔에 에러 로그 기록 + 사용자에게 일반 오류 메시지 표시

## 테스트 방법

빌드 도구가 없는 정적 페이지이므로 자동화 테스트 대신 브라우저 수동 확인 체크리스트로 검증한다.

- [ ] 개 사진 업로드 → "개입니다" 표시 확인
- [ ] 고양이 사진 업로드 → "고양이입니다" 표시 확인
- [ ] 사람/풍경 등 무관한 사진 업로드 → "보이지 않습니다" 표시 확인
- [ ] 이미지가 아닌 파일(예: .txt) 업로드 → 에러 메시지 확인
- [ ] 드래그앤드롭 업로드 동작 확인
- [ ] 클릭을 통한 파일 선택 업로드 동작 확인

## 범위 제외 (Out of Scope)

- 로그인/계정, 사용자별 히스토리 저장
- 카메라 촬영 입력
- 백엔드 서버, API 키, 데이터베이스
- 다중 이미지 배치 처리
