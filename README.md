# 🐶 개 고양이 판별기 🐱

사진을 올리면 개인지 고양이인지 판별해주는 웹 서비스입니다. 판별은 브라우저 안에서 이루어지므로 서버도, API 키도 필요 없고 사진이 외부로 전송되지 않습니다.

![스크린샷](docs/screenshot.png)

## 실행 방법

정적 파일이라 별도 빌드 과정이 없습니다. 저장소를 받은 뒤 로컬 서버를 띄우고 브라우저로 접속하면 됩니다.

```bash
python3 -m http.server 8123
```

http://localhost:8123 에서 확인할 수 있습니다.

## 사용법

1. 페이지에 접속하면 판별 모델을 내려받습니다. `준비 완료!`가 뜨면 사용할 수 있습니다.
2. 드롭존에 사진을 끌어다 놓거나 클릭해서 파일을 선택합니다.
3. 판별 결과가 신뢰도와 함께 표시됩니다.

결과는 세 가지 중 하나입니다.

- `🐶 개입니다 (신뢰도 87%)`
- `🐱 고양이입니다 (신뢰도 92%)`
- `❓ 개나 고양이로 보이지 않습니다`

## 동작 방식

TensorFlow.js와 사전학습 모델 MobileNet을 CDN에서 불러와 브라우저에서 직접 추론합니다.

MobileNet은 ImageNet의 1000개 범주를 분류하는데, 그중 개 품종이 약 120개, 고양이가 5개를 차지합니다. 상위 5개 예측 중 개 관련 클래스의 확률과 고양이 관련 클래스의 확률을 각각 합산한 뒤, 더 높은 쪽이 30% 이상이면 그 결과를 보여줍니다. 둘 다 30%에 못 미치면 개나 고양이가 아닌 것으로 판단합니다.

클래스명을 키워드로 매칭하는 방식이라 오탐 여지가 있어 몇 가지를 따로 처리했습니다. `Madagascar cat`은 실제로는 여우원숭이이고 `cardigan`은 스웨터라서, `cat`이나 `cardigan` 같은 넓은 키워드 대신 `tiger cat`, `welsh corgi`처럼 구체적인 표현으로 매칭합니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 페이지 구조 |
| `style.css` | 스타일 (다크 모드 지원) |
| `app.js` | 모델 로딩, 이미지 처리, 판별 로직 |

설계 문서는 [docs/superpowers/specs](docs/superpowers/specs)에 있습니다.

## 알려진 한계

- 개와 고양이만 구분합니다. 다른 동물은 모두 "보이지 않습니다"로 처리됩니다.
- 첫 접속 시 모델을 내려받기 때문에 네트워크 상태에 따라 몇 초 걸릴 수 있습니다.
- 인터넷 연결이 필요합니다. 모델을 CDN에서 불러오기 때문입니다.
